# 02 Source Recipes｜焙度死表退役與來源選方（SSOT）

## 退役邊界
原五檔焙度溫度／比例／研磨表、批次水量研磨與脈衝降階表已退役，不作新配方原點、不作查無匹配時 fallback，也不從 archive 偷取舊數字。歷史版本保留供追查，不重寫舊實飲。

焙度、海拔、處理法與風味詞是選方與解釋的特徵，不能直接產出一組沖煮數字。

## 完整來源配方是起點
查 `aiden_kb.search_recipes`，讀完整配方、作者原意與來源證據，再依 01 判定身分。預設選一支完整母配方，列相符、差異、未知與選它的理由；來源語句、助手假說與使用者實飲分開標示。

選來源時確認設備、熱沖／冷萃、低因狀態、實際單杯／批次路徑與必要參數。文章可含多豆、多設備、多連結，必須對應正確區塊；不得只拿第一個 brew.link，或用手沖配方填 Aiden 的未知欄位。

原文、brew.link、驗證器衝突時保存差異並待核對，不默默改值。來源提供 rest 建議只適用該來源／豆款，不轉成通用新鮮度公式。

## 無精確匹配時
可用 `green_coffee_related`、`feature_analog` 或 `flavor_intent` 做有目的的探索，無須要求使用者每次先開實驗模式。保留完整母配方與逐參數改編理由，不將弱匹配稱官方同豆配方。

沒有足夠完整來源時先補查；仍不足可暫不生成。以已驗證結構做低信心設計也須明示其來源、缺口及外部驗證結果，不假裝作者曾提供或使用者曾喜歡。
