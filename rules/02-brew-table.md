- 焙度查表即得，不插值、不發揮。
- Ratio 只看焙度（海拔 CV 不顯著、不加）；BloomRatio 另加海拔：>1800m +0.2、<1300m −0.2、中間不調 → 加完才 snap。
- 單杯 3 脈衝全焙度每段降 −0.5°C（首段溫仍依焙度）。
- 批次預設 3 段、首段溫＝該焙度單杯首段、每段遞降約 −1.0°C、降階幅度隨水量放大（見 03 批次脈衝水量表）。間隔 30s。
