ChatGPT 設定與能力驗收

本站網址：https://ga815647.github.io/fellow-aiden-guide/；是否已部署請以該網址的 version.json 與實際內容為準。以下是手動操作指南，不是此帳戶或目標 Project 已驗收的聲明；網站可讀也不代表 ChatGPT 已能讀取或使用工具。

官方依據與未驗證邊界（2026-09-26 查核）

  • ChatGPT developer mode 官方文件：網頁版列 Pro、Plus、Business、Enterprise、Education 可用；MCP 讀／寫工具，SSE／streaming HTTP；驗證列 OAuth、No Authentication、Mixed Authentication。這是官方能力清單，不保證你的帳戶已開通，也未證明工具可在指定 Project 使用。Help Center 的未核實搜尋索引差異不作原頁結論。
  • Apps SDK 驗證文件：OAuth Bearer 是授權流程產生的 access token，不是可直接填入既有固定 API key；文件亦指出 ChatGPT 不能提交自訂 API key。既有 Aiden MCP README（私人工作區）描述 Streamable HTTP /mcp、固定 MCP_AUTH_TOKEN 的 Bearer／Claude.ai query-token 接法；它沒有證明 ChatGPT 相容。固定 token 認證、query-token URL 在 ChatGPT 的可用性都未實測；請勿在網址、對話、截圖或上傳檔洩漏 token。若認證不相容，記錄實際錯誤與阻礙，不在此流程更改伺服器或驗證方式。

安裝規則與指示

  1. 在實際使用的 Project Instructions 放下方固定薄入口；完整指示 由 Git 維護，日後改完整指示不必重貼。維護者另提供私人 Neon 定位；本專案私人工作區的 docs/guide/project-bootstrap-private.md 已組好完整貼用版。未收到使用者貼上確認前只算入口備妥。一般對話可使用同樣入口，但不假設其他對話或 Project 自動繼承工具。
  2. 有 GitHub MCP／connector 檔案讀取能力時，優先直接讀 repo ga815647/fellow-aiden-guide 的 version.json、rules.md，入口 ref main；支援時解析並固定同一 commit，不先嘗試 Pages 或搜尋。不能固定 ref 時，讀取前後確認版本檔一致。GitHub 不可讀再用本站同名檔，最後才用同版完整上傳檔。報出建置時間、rulesSha256、實際來源與 00–06 必要段落；讀到 manifest 的 hash 不等於已重算檔案 bytes 驗證。附件更新時重傳，版本衝突先選定一版。

工具與製表驗收（在 ChatGPT 介面手動執行）

  1. 依官方介面開啟 Developer mode、新增遠端 MCP app（僅在認證相容且有安全設定途徑時），在實際要使用的入口檢查 validate_aiden_profile、create_aiden_brew_link 清單。若目標 Project 不支援自訂 MCP，才驗收一般聊天備援入口並在該入口貼指示、讀規則；一般對話成功不算 Project 成功。無法安全連線時標記未驗證並停止工具驗收，不試填固定 token／query-token URL。
  2. 在該實際使用入口，以同版 SSOT 推得的完整合法測試 payload只呼叫 validate_aiden_profile；核對 valid: true 與回傳內容。驗證失敗記錄錯誤，不呼叫 create_aiden_brew_link。建立測試 profile 不是必要驗收；真正明確要求建立時才遵守 validate → create，ChatGPT 工具寫入確認仍以實際介面為準。
  3. 維護者以私人補充交接 Neon project_id、database 及必要表定位；需要定位的呼叫明確帶入，不依賴 list_projects。唯讀確認所需結構即可，歷史 nullable／已知缺值先查契約，不擴成全庫稽核。401 記為當前認證失敗，恢復後做最小唯讀確認；不能查不當成查無紀錄。寫入留待真實授權業務操作。
  4. 停止條件：指示已貼、必要完整規則已讀、必要唯讀查詢成功、validate 實測通過，即可開始日常使用。工具可見／呼叫成功／業務成功分開記錄；不為完成設定強制建立 profile、寫 DB 或追加製表測試。首次真實配方仍依規則核對原點、單杯／批次與三塊輸出；設定通過不宣稱每次製表必然正確。使用者貼回的執行報告標為使用端回報證據，不寫成 OpenCode 親自實測，也不外推其他入口或認證方式。
