ChatGPT 設定與能力驗收

本站網址：https://ga815647.github.io/fellow-aiden-guide/；是否已部署請以該網址的 version.json 與實際內容為準。以下是手動操作指南，不是此帳戶或目標 Project 已驗收的聲明；網站可讀也不代表 ChatGPT 已能讀取或使用工具。

官方依據與未驗證邊界（2026-09-26 查核）

  • ChatGPT developer mode 官方文件：網頁版列 Pro、Plus、Business、Enterprise、Education 可用；MCP 讀／寫工具，SSE／streaming HTTP；驗證列 OAuth、No Authentication、Mixed Authentication。這是官方能力清單，不保證你的帳戶已開通，也未證明工具可在指定 Project 使用。Help Center 的未核實搜尋索引差異不作原頁結論。
  • Apps SDK 驗證文件：OAuth Bearer 是授權流程產生的 access token，不是可直接填入既有固定 API key；文件亦指出 ChatGPT 不能提交自訂 API key。既有 Aiden MCP README（私人工作區）描述 Streamable HTTP /mcp、固定 MCP_AUTH_TOKEN 的 Bearer／Claude.ai query-token 接法；它沒有證明 ChatGPT 相容。固定 token 認證、query-token URL 在 ChatGPT 的可用性都未實測；請勿在網址、對話、截圖或上傳檔洩漏 token。若認證不相容，記錄實際錯誤與阻礙，不在此流程更改伺服器或驗證方式。

安裝規則與指示

  1. 在 ChatGPT 建立目標 Project，將 指示全文 貼到 Project settings 的 instructions；未貼上並確認前只算文件備妥。若一般對話才有可用工具，也可複製同份指示到該對話；不承諾 Project 自動繼承一般對話工具或設定。
  2. 要求 ChatGPT 實際讀取 完整規則，報出 version.json 的建置時間與 rulesSha256，指出 00–06 所需條件與來源；僅貼網址不算讀取。若 Project 讀取線上內容不穩，下載同版 rules.md 上傳到 Project 並重新驗收讀取。規則更新後重新上傳；若線上與附件版本不同，先明確指定只用哪版，不混算。

工具與製表驗收（在 ChatGPT 介面手動執行）

  1. 依官方介面開啟 Developer mode、新增遠端 MCP app（僅在認證相容且有安全設定途徑時），在一般對話列出 validate_aiden_profile、create_aiden_brew_link；再於目標 Project獨立檢查同一清單與可見性。若 Project 不支援自訂 MCP，記下已通過驗收的一般聊天入口，改在該入口貼指示與讀規則；不要將一般對話成功當成 Project 成功。若任一入口無法安全連線，標記未驗證並停止工具驗收，不試填固定 token／query-token URL。
  2. 在每個有工具的入口，以同版 SSOT 推得的完整合法測試 payload只呼叫 validate_aiden_profile；核對 valid: true 與回傳內容。驗證失敗記錄錯誤，不呼叫 create_aiden_brew_link。建立測試 profile 不是必要驗收；真正明確要求建立時才遵守 validate → create，ChatGPT 工具寫入確認仍以實際介面為準。
  3. Neon 另行確認連至 fellow-aiden 專案，以唯讀方式確認回饋、海拔及 overlay 所需表與欄位可見（schema 由工作區維護，勿在公開站揭露私有資料）。不能查時不當成「查無紀錄」；未經真實授權業務操作驗收的回饋寫入標記未驗證，不為測試任意修改 DB。
  4. 在實際要使用的 Project 或已驗收的一般對話，提供輸入齊全、來源可追溯的新豆案例，要求讀完整同版規則，核對原點、單杯／批次、Overview／操作表格／機器參數、合法刻度、計算與顯示精度；只測網站可開或工具清單不足以證明製表正確。無必要資料、Neon／規則不可讀、validate／create／DB 失敗時不宣稱連結或紀錄成功。

日後更新

規則變動後由維護者重新建置發布；比對本站 version.json 與新 rules.md，重新貼上新版 instructions（若有變動）、重新上傳同版附件並做讀取與製表驗收。分別記錄：文件上線、指示安裝、一般對話與 Project Aiden 工具、Neon 唯讀／寫入及實際製表的狀態；本地 OpenCode 測試不可代替 ChatGPT 驗收。
